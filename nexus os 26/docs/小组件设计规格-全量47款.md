# Nexus OS 26 · 小组件设计规格（全量 47 款 / v1 · 2026-11-13）

> 用户原话：「你给每一个小组件都稍微思考一下，列个 MD，它应该长什么样？以及功能应该要放在哪里？并且最重要的保证不要溢出，然后再重新开始做。」

> **本文件是重做依据，不是实现报告。** 先定规格，再按 §4 的顺序逐卡落地。实现与本文冲突时改实现；要改规格先在这里改，别在 CSS 里偷偷改口径。

## 1 · 全局铁律（重做前必读）

1. **一套玻璃，各表身份**：昼浅玻璃 / 夜半透深蓝，任何档不许纯黑；类别身份只落在内容点缀 `--w-accent`，不刷整卡。
2. **不扭曲**：卡面只许平整玻璃 + 线性渐变；封死 radial 大光斑、位移折射、`backdrop-filter` 重采样、误注入的 optics 子层。
3. **昼墨夜白**：昼 `#0b1220`、夜 `#eef2fa`。CSS 变量在最近祖先解析，令牌必须打到 `.widget-inner` 与内容层根；旧 CSS 的直写 `color:#fff` 一律由「兜底 + 恢复」两条简单规则收口。
4. **音乐族例外**：图像承载型介质卡，走 `ml2` 半透深蓝磨砂唱片面 + 白字白控件；2×2 是老版 GitHub `d71b821` 的「圆角封面 + 独立标题行 + 底边 2px 进度」，不许封面负 margin 铺满、不许底部渐变压字。
5. **四风格**：`flat` / `neu-solid` / `neu-glass` / `liquid`。Flat 与 Liquid 共用「平」骨架，只有 Neu / 玻璃拟物有凹凸；卡面颜色不随风格换，只差阴影与边。
6. **光**：`go8` 导光板模型——四条侧边等亮注入、整面同时提亮，不是波带、不是流动光斑、不是涟漪。
7. **图标**：G2 连续曲线（`sq2`），全部图标无一例外。
8. **数据诚实**：外部数值先过 `numOrNull()`，缺数据写 `--`，绝不写 0° / AQI 0 优。
9. **性能**：零逐卡片 JS、零 MutationObserver、零布局读、零 `filter` 祖先、零 `transition:all`；时钟每秒只写 `textContent`。

## 2 · 不溢出总规范（最高优先级）

### 2.1 三层盒模型

```
.desktop-widget-card   overflow:hidden / border-radius / 唯一裁切边界
└─ .widget-inner        padding: var(--w-pad,14px) / min-width:0 / min-height:0 / height:100%
   └─ 内容层根 .nx .nx2 .nx-mu .nx-bili   display:flex / min-width:0 / min-height:0 / max-width:100%
```

- 卡片是**唯一**裁切边界；内容层根不许出现负 margin 撑出去（音乐 `.nx-mu-bg` 是唯一例外，见 2.6）。
- 任何 flex 子项都必须 `min-width:0`，否则长文本会把整行撑破。
- 所有容器 `max-width:100%`，任何子元素的 `width` 不许写死大于父级。

### 2.2 文本

- 主数字：`clamp(下限, 相对卡高/宽, 上限)` + `font-variant-numeric: tabular-nums` + `white-space:nowrap`；不许靠 `font-size` 硬值在大卡/小卡间通用。
- 单行标签：`overflow:hidden` + `text-overflow:ellipsis` + `white-space:nowrap` + `min-width:0`。
- 多行标题：`display:-webkit-box` + `-webkit-line-clamp:1|2` + `word-break:break-word`；行数**按档位写死**，不许「能放几行放几行」。
- 时间 / 数值 / 百分比：`tabular-nums`，避免每秒重排。

### 2.3 列表 / 网格 / 图

- 列表 `flex:1 1 auto` + `min-height:0` + `overflow:hidden`（需要滚动才用 `overflow-y:auto`，且滚动条必须在卡片内）。
- **行数、格数、卡片数按 `cols×rows` 写死上限，多出来的数据不渲染**，绝不靠压缩行高硬塞。这是「按尺寸换内容」而不是「等比缩小」的核心。
- 网格 `grid` 等分 + 每格 `min-width:0`；图片一律 `object-fit:cover` + 容器 `overflow:hidden`。
- 圆盘 / 封面 / 表盘：`aspect-ratio:1` + `max-height:100%`，卡再矮也只缩不溢出。

### 2.4 控件

- 按钮尺寸固定（`flex:none`），最小触控区 22px；控制条 `flex:none` 锁高，永远不与主读数抢高度。
- 所有交互元素 `onmousedown="event.stopPropagation()"`，避免误触发卡片拖拽。
- `rows=1` 胶囊档：隐藏所有非必要控件，只留「图标 + 主值 + 一个动作」；圆角 999px 由双写属性选择器压过四风格。

### 2.5 尺寸分档 = 换内容，不是等比放大

| 档型 | 网格 | 信息层级 |
| --- | --- | --- |
| 胶囊 | `6×1` / `4×1` | 图标 + 主值 + 一个动作，其余全隐藏 |
| 小方 | `2×2` | 主值 + 1 个辅助标签 + 1 个状态件 |
| 竖长 | `2×3` / `3×4` | 主值 + 列表 3~5 行 |
| 横宽 | `3×2` / `4×2` / `6×2` | 主值 + 2~4 个横向指标 / 迷你图 |
| 大方 | `4×3` / `3×3` | 主值 + 图 + 列表 4 行 + 底部控件 |
| 特大 | `4×4` / `6×3` | 全套 + 明细 / 图例 |

### 2.6 音乐族例外（★ 2026-11-15 作废，见 §5.10）

~~`.widget-inner` 对音乐卡设 `overflow:visible`，让 `.nx-mu-bg` 用 `-14px` 负 inset 铺到卡边。~~
**已作废**：`ml3` 起「专辑图只待在封面格、`.nx-mu-bg` 全卡铺图作废」，这条 `overflow:visible` 是没删干净的旧定案残留，实机上把 2×3 音乐卡拉成竖长条、封面与灰底割裂、内容溢出卡片。`ml5` 已把音乐族 `.widget-inner` 与 `.nx.nx-mu` 双双收回 `overflow:hidden`，卡片仍是唯一裁切边界；`pc1` §3 另给封面固定方形格与信息区弹性占位。

### 2.7 验收清单（每卡都要过）

- [ ] **16 种网格**（12 显式 + 4 个派生 5 列档）逐档检查，无横向/纵向溢出、无滚动条露在卡外
- [ ] 最长文本（超长歌名 / 城市名 / 日程标题）不撑破布局
- [ ] 空数据 / 缺数据态不塌陷、不编数值
- [ ] 四风格 × 昼/夜 × 深色模式 = 8 态，文字对比度都够
- [ ] 面板预览卡（`wcols-N/wrows-N`，无 `data-cols/rows`）同样不溢出
- [ ] 纯 Node 静态验收：CSS 剥注释后括号配平、无禁紫色值、戳全同步

## 3 · 逐卡规格（47 款）

### 时间族（7）

#### 01 时钟 `clock` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 4×4 / 6×1
- **长什么样**：浅玻璃卡，超大等宽数字占左半，右侧竖排星期/日期小字；秒点用身份色，不做黑底。
- **功能放在哪**：整卡只读，点击进时钟应用；小档不放任何按钮。
- **尺寸层级**：2×2 → HH:MM + 星期；4×2 → 加日期；4×3/4×4 → 加秒点与农历；6×1 → 单行 HH:MM + 星期。
- **不溢出**：数字 `clamp()` 随卡宽缩 + `min-width:0`；6×1 隐藏星期/日期整行。

#### 02 秒级时间 `timeSeconds` · 默认 3×2 · 3×2 / 2×2 / 4×2 / 6×2 / 6×1
- **长什么样**：主时钟右挂小一号秒数，秒数吃 `--w-accent`；其余与 clock 同皮。
- **功能放在哪**：只读，无控件；秒数由 plus.js 单一 1s interval 写 `textContent`，不重建 DOM。
- **尺寸层级**：2×2 → 只 HH:MM；3×2/4×2 → +SS；6×2 → +日期；6×1 → HH:MM:SS 一行。
- **不溢出**：秒数 `tabular-nums` + `flex:none`；6×1 绝不换行，动画不每秒重播。

#### 03 模拟时钟 `clockAnalog` · 默认 2×2 · 2×2 / 3×3 / 4×3 / 4×4
- **长什么样**：圆形表盘居中，刻度与指针走墨色、秒针走身份色；不要拟物金属渐变。
- **功能放在哪**：只读；表盘自身不接点击，整卡进时钟应用。
- **尺寸层级**：2×2 → 纯表盘；3×3 → +数字时间小字；4×3/4×4 → +日期与星期两行。
- **不溢出**：表盘 `aspect-ratio:1` + `max-height:100%` + SVG `viewBox` 固定。

#### 04 世界时钟 `worldclock` · 默认 4×2 · 4×2 / 3×2 / 4×3 / 6×2
- **长什么样**：横向 2~4 个城市列，每列「城市名 + 时间 + 昼夜小标」；列间细分隔线，不高亮整列。
- **功能放在哪**：点城市列切换该城为主时区；列是唯一交互区。
- **尺寸层级**：3×2 → 1 列；4×2 → 2 列；4×3 → 3 列 + 日期；6×2 → 4 列。
- **不溢出**：列数按 `cols` 算上限，多出城市**不渲染**；每列 `flex:1 1 0` + `min-width:0`。

#### 05 双区时间 `dualtime` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 6×2 / 4×1
- **长什么样**：上下（宽档左右）两块等大的时间区，北京 + 自选城市，中间一条身份色短线。
- **功能放在哪**：自选那块可点弹城市选择；北京块只读。
- **尺寸层级**：2×2 → 上下两行；4×2/6×2 → 左右两栏 + 日期；4×3 → +时差说明；4×1 → 一行「北京 08:30 · 纽约 19:30」。
- **不溢出**：两块各 `flex:1 1 0` + `min-width:0`；4×1 压成单行不换行。

#### 06 计时秒表 `stopwatch` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 6×1
- **长什么样**：大号计时读数 + 下方一行计次；运行态细进度呼吸，静止无动画。
- **功能放在哪**：开始/暂停/复位三键固定在底部控制条，不与读数抢高度。
- **尺寸层级**：2×2 → 读数 + 三键；4×2 → +最近 1 次计次；4×3 → +3 行计次列表；6×1 → 读数 + 一个开始键。
- **不溢出**：控制条 `flex:none` 锁 28px；读数 `clamp` 单行；计次列表 `overflow-y:auto` 裁在卡内。

#### 07 倒计时 `countdown` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 6×1
- **长什么样**：剩余天/时分秒大数字 + 一条细进度条表示已过比例；到期态换身份色。
- **功能放在哪**：底行一个「重置」；点数字区进入编辑目标时间。
- **尺寸层级**：2×2 → 主数字 + 条；4×2 → +目标日期；4×3 → +说明文字；6×1 → 「X 天 HH:MM」一行。
- **不溢出**：进度条 `flex:none` 3px；大数字 `clamp` 不换行。

### 天气族（7）

#### 08 天气 `weather` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 4×4 / 6×1
- **长什么样**：左大温度 + 右天气图标，下方城市与描述；天蓝身份色只落在图标与 AQI 徽标。
- **功能放在哪**：整卡只读，点击进天气应用；小档不放刷新键。
- **尺寸层级**：2×2 → 温度 + 图标 + 城市；4×2 → +高低温；4×3/4×4 → +AQI/风力两行；6×1 → 图标 + 温度 + 描述一行。
- **不溢出**：温度先过 `numOrNull()`，缺数据写 `--°` **不写 0°**；城市名单行省略号。

#### 09 逐时天气 `weatherHour` · 默认 4×2 · 4×2 / 3×2 / 6×2 / 4×3
- **长什么样**：横向等宽逐时小柱「时 + 图标 + 温度」，当前时用身份色细下划线。
- **功能放在哪**：只读；逐柱不接点击（放不下触控区）。
- **尺寸层级**：3×2 → 3 柱；4×2 → 4 柱；6×2 → 6 柱；4×3 → 6 柱 + 一行降水概率。
- **不溢出**：柱数按 `cols` 上限截断，每柱 `flex:1 1 0` + `min-width:0`；无逐时数据显示「暂未就绪」。

#### 10 七日天气 `weatherWeek` · 默认 4×3 · 4×3 / 3×2 / 4×2 / 6×3
- **长什么样**：每日一行「星期 / 图标 / 高低温 / 细温差条」，今日行轻高亮。
- **功能放在哪**：只读。
- **尺寸层级**：3×2/4×2 → 2 行；4×3 → 4 行；6×3 → 6 行。
- **不溢出**：行数按 `rows` 写死上限，列表 `overflow:hidden`，多出的不渲染；高低温 `tabular-nums`。

#### 11 空气质量 `airQuality` · 默认 2×2 · 2×2 / 3×2 / 4×2 / 4×3 / 6×2
- **长什么样**：大 AQI 数值 + 等级胶囊 + 分段色条；色条只用绿/黄/橙/红，禁紫。
- **功能放在哪**：只读；等级胶囊不接点击。
- **尺寸层级**：2×2 → 数值 + 等级；3×2/4×2 → +色条；4×3 → +PM2.5 一行；6×2 → +两项污染物。
- **不溢出**：缺数据写 `--` **绝不写「AQI 0 优」**；数值 `clamp`，色条 `flex:none`。

#### 12 日出日落 `sunrise` · 默认 3×2 · 3×2 / 2×2 / 4×2 / 6×1
- **长什么样**：一条地平线弧线 + 太阳位置点 + 两端时刻标签；弧线是信息图，不是装饰光。
- **功能放在哪**：只读。
- **尺寸层级**：2×2 → 弧线 + 两端时刻；3×2/4×2 → +当前高度角；6×1 → 「↑06:12 ↓17:48」一行。
- **不溢出**：弧线 SVG `viewBox` + `width:100%`；标签 `white-space:nowrap`；6×1 压成文字摘要。

#### 13 日月轨迹 `sunmoon` · 默认 4×2 · 4×2 / 2×2 / 6×2 / 6×1
- **长什么样**：上下两条轨迹带，日轨暖色、月轨冷色，右侧给出当前高度角。
- **功能放在哪**：只读。
- **尺寸层级**：2×2 → 只日轨摘要；4×2 → 双轨；6×2 → 双轨 + 两端时刻；6×1 → 一行文字摘要。
- **不溢出**：两条带各 `flex:1 1 0` + `min-height:0`；6×1 不画轨迹。

#### 14 月相 `moonphase` · 默认 2×2 · 2×2 / 3×2 / 4×3
- **长什么样**：圆形月相图居中 + 下方名称与农历日；明暗用纯色遮罩，不用星空黑底。
- **功能放在哪**：只读。
- **尺寸层级**：2×2 → 圆盘 + 名称；3×2 → +农历日；4×3 → +一行说明。
- **不溢出**：圆盘 `aspect-ratio:1` + `max-height:100%`；4×3 才补说明文字。

### 日历族（8）

#### 15 日历 `calendar` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 4×4 / 6×1
- **长什么样**：顶部月份行 + 7 列日期格；今日身份色实心圆，选中态另有细环。
- **功能放在哪**：点日期格选中；点月份行进日历应用。
- **尺寸层级**：2×2 → 只本周 7 格；4×2 → 两行 + 月份；4×3/4×4 → 整月；6×1 → 「11月12日 周三」一行。
- **不溢出**：格子 `grid` 等分 + `min-width:0`；**2×2 不硬塞整月**；6×1 不画格子。

#### 16 作息计划 `schedule` · 默认 2×2 · 2×2 / 4×2 / 4×3 / 4×4 / 6×1

### 5.11.1 动画 `ui/n26-widget-drawer-motion.css|js?v=dm1`

CSS 尾链**最后一层**（排在 `pc1` 之后），JS 排在 `drawer.js` 之后，主壳业务零改动。三条真因与对应手法：

| # | 病根 | 修复 |
| --- | --- | --- |
| ① | `widgets.css` v4 段 `transition: opacity 160ms ... !important` 覆盖 `perf.css` 的 `visibility 0s linear .32s` 延迟，关闭瞬间 hidden | `dm1` 给 overlay `transition:none !important`；`visibility` 改由状态类 `!important` 显式托管 |
| ② | 面板位移被 `widgets.css` / `drawer.css` / `perf.css` 三份 `transform: ... !important` 锁死，CSS animation 优先级低于 `!important` | 位移改用独立属性 **`translate`**（Transforms Level 2），与 `transform` 互不冲突；`dm1` 再把 `transform` 统一归零，清掉 10px 微位移与 `.985` 缩放 |
| ③ | `openWidgetPanel()` 首次 reparent 到 body，DOM 重挂载吃掉 transition 上一帧起点 | 全程 `animation + fill-mode:both`，不依赖起点；`void p.offsetWidth` 一次性重放 |

状态机 `idle → n26-dm-in → n26-dm-open → n26-dm-out → idle`：入 460ms / 出 340ms；`in` 与 `open` 绝不共存（`open` 的 `translate:none !important` 会压过动画）；退场途中重新打开会清掉 `out` 并重放 `in`。退场期补回 `backdrop-filter`，压过 `perf.css` 对 `:not(.show) .glass` 的摘模糊；`body.n26-dm-closing` 全程把 Dock / Finder Bar 压到 90。`prefers-reduced-motion` 只缩短到 140ms，不砍成 0。性能模式的 `animation:none` 因本层带 ID 特异度 + `!important` 而不生效。

### 5.11.2 溢出与空当 `drw6 / grp4`

- **尺寸滑轨**：按软件分组后是冗余整行，`display:none`（DOM 保留，`n26BindSizeSlider` 绑定不受影响）。
- **组头**：8 个 `width:100%` 大横条 → 行内紧凑 chip（图标 + 软件名 + 款数 + 箭头），`position` 由 sticky 改 relative；副标题 / 已添加徽标收掉。

- **预览框 3D 悬停全撤**：`widgets.css` v4 段的 `perspective(760px) rotateX/Y`、`transform-style:preserve-3d`、`will-change:transform` 会让卡片内容脱离 `contain:paint` 画到框外，是「溢出」的另一条真因。抽屉里不需要悬停翻转，`transform:none / transform-style:flat / perspective:none / will-change:auto`。
- 卡片名称 / 尺寸条再收 3px，组间用一条极淡分隔线代替空白。
